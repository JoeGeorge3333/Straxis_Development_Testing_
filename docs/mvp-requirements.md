# Fitness Challenge Platform — MVP Requirements (v1)

Date: 2026-04-17

## Product summary
A competitive fitness accountability platform for friend groups: log daily actions, earn points, and compare standings in a league.

The MVP is intentionally narrow: **75 Hard** only, **fixed scoring**, and a **core loop** of:

**Log → Score → Compare**

## Target users
- People doing 75 Hard (or similar) who want competitive pressure.
- Small friend groups (2–20) who want visibility + accountability.

## Core user stories (must-have)
- As a user, I can create an account and log in.
- As a user, I can join a league via an invite code.
- As a user, I can see my **day number**, **streak**, and **today’s score**.
- As a user, I can log up to **two workouts** for today, including duration and whether it was outdoor.
- As a user, I can complete daily 75 Hard habit tasks (checkboxes).
- As a user, I can see a league leaderboard ordered by total points.
- As a user, I can see a lightweight activity feed of events (auto-generated by logs).
- As a user, I can view my profile and sign out.

## Non-goals (explicitly out of scope for MVP)
- Workout sets/reps/exercise detail tracking
- Photo uploads / progress photos as media
- Weekly matchups / head-to-head schedules
- Configurable scoring weights per league
- Comments, reactions, social posting
- Real-time updates (polling only)
- AI coach/agent insights

## Scoring (fixed 75 Hard defaults)
Daily maximum: **50 points**

| Task key | Points | Max/day | Input |
|---|---:|---:|---|
| `workout_completed` | 10 | 2 | Workout log |
| `workout_outdoor` | 5 | 1 | Workout flag |
| `diet_compliance` | 10 | 1 | Checkbox |
| `water_gallon` | 5 | 1 | Checkbox |
| `reading_done` | 5 | 1 | Checkbox |
| `progress_photo` | 5 | 1 | Checkbox (no upload in MVP) |

## UX requirements (mobile)
- The primary screen should mirror the wireframe:
  - streak / day info
  - user vs opponent points comparison (progress bar)
  - matchup section (user vs opponent cards)
  - daily tasks checklist
  - bottom navigation (icons)
- Show states for:
  - loading / refreshing
  - offline / API error (retry)
  - empty state for “no league joined”

## MVP acceptance criteria
- A fresh install can register, log in, join a league, and see the dashboard populated from the backend API.
- Logging a workout or habit updates:
  - today’s score
  - league leaderboard (after refresh/poll)
  - activity feed (after refresh/poll)
- No part of the MVP requires admin access once at least one league exists.
