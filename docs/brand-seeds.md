# Brand Seeds — Fitness Challenge Platform (MVP)

Date: 2026-04-17

## Working brand idea
**Name (placeholder):** STRAXIS  
**Tagline (draft):** Fantasy-sports intensity for the 75 Hard grind.

## Brand pillars
- **Competitive accountability:** the app applies pressure in a motivating, non-cringe way.
- **Clarity + speed:** logging takes seconds; feedback is immediate.
- **Earned status:** streaks, points, and rank feel “won”, not “given”.
- **Minimal but premium:** fewer features, better focus.

## Voice & tone
- Direct, punchy, confident.
- Short sentences. Strong verbs.
- Avoid “wellness fluff”; lean into “performance + accountability”.

Examples:
- “Close the day strong.”
- “Your league is watching.”
- “Earn the last 15.”

## Visual identity direction
### Color system (new scheme)
This palette is implemented in:
- Mobile: `mobile/src/theme/colors.ts`
- Web prototype: `styles.css` (`:root` vars)

Core tokens:
- **Background:** `#05070D`
- **Surface:** `#0B1020`
- **Surface (alt):** `#0F1730`
- **Text:** `#F2F6FF`
- **Primary (mint):** `#78F7C0`
- **Primary (alt):** `#2EE59D`
- **Accent (blue):** `#6CA8FF`
- **Danger:** `#FF5A6A`

### Typography
- Display: condensed, athletic (e.g. Avenir Next Condensed / similar).
- Body: clean sans (e.g. Avenir Next / Inter).
- Use uppercase micro-labels for “scoreboard” vibes.

### UI motifs
- “Scoreboard” components: progress bars, pills, rank badges.
- Subtle grid/noise + soft glow accents (primary + accent).
- Rounded geometry (14–18px radii) for a premium feel.

### Iconography
- Bold outline icon set (Ionicons in MVP).
- Bottom nav: icons only (no labels) to match the wireframe.

## Brand stretch goals (post-MVP)
- League identity packs (team colors, emblems).
- Animated streak celebrations and rank movement.
- Shareable “daily recap” cards.
