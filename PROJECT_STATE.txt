2. WEB APP (web/) — CURRENT FOCUS
================================================================================
Stack:
  - Vite 7, React 19, TypeScript, react-router-dom 6
  - Run: cd web && npm install && npm run dev  →  http://localhost:5173 (default)

Routes (all under AppLayout: header + bottom nav + main):
  /                 Dashboard: Tasks (active league challenge) | League panel
  /tasks/:taskId    Task detail / log submit
  /tasks/new        Add challenge task (league owner only)
  /data             Data / logs (filtered by active league when applicable)
  /league           League hub: access key, copy, members, matchup, leaderboard, mock chat
  /league/create    Create league (generates access key)
  /league/join      Join by access key (e.g. STRX-DEMO for starter)
  /league/challenge Owner: edit shared challenge task list
  /profile          Settings stub + link to emoji picker
  /profile/emoji    Avatar emoji grid

State (web/src/state.tsx):
  - In-memory React reducer (no backend): users, leagues, activeLeagueId, challenge tasks per league,
    taskProgress (per user, per task), rollDayKey + day/tick for daily reset of completions,
    logs, leagueChat (mock), leagueJoinError
  - League has: name, accessKey, ownerId, memberIds, challengeTasks[], startedOnDayKey (program day)

UI highlights:
  - Top bar: avatar | STRAXIS + challenge name + DAY n | +
  - Bottom nav: Dashboard | Data/Logs | League
  - STRAXIS brand styling in web/src/styles.css (gold / void palette)

Planning (not implemented):
